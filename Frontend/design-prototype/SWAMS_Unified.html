Discovery — Problem Statement

Through 18 stakeholder interviews across HR, management, and employee levels, we identified a core friction cluster: attendance management was fractured across 4+ tools with no single source of truth.

HR spends 40% of Monday morning manually reconciling attendance spreadsheets.
I forget to clock in at least twice a week. The system is buried too deep.
Leave approval is still done by email. It's 2026.
HMW Statements
How might we reduce clock-in friction so employees complete it without thinking?
How might we give HR predictive insights instead of reactive reports?
How might we make task revision feedback transparent without creating blame culture?
How might we unify 4 tools into one platform without overwhelming users?

Key Design Decisions & Rejected Alternatives
✓ Chosen: One-tap clock in sidebar
Persistent bottom CTA reduces cognitive load. Clock-in stays visible on every page.
✗ Rejected: Dedicated clock-in page
Required 3 taps minimum. User testing showed 60% abandonment before first month.
✓ Chosen: 5-lane Kanban with revision lane
Separate revision lane makes feedback visible. Color coding prevents review/revision confusion.
✗ Rejected: Comments in external tool
Slack/email comments get lost. 78% of staff missed revision notes in testing.
